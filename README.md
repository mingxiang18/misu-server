# misuServer

- 使用Java语言开发的个人应用服务端

### 模块划分
- misu-account：认证和账号模块（认证、授权、用户管理）
- misu-bot：机器人通讯模块
- misu-file-server：文件存储服务模块
- misu-gateway：网关模块
- misu-net：网络代理等相关工具
- misu-framework：框架公共模块
- |---- misu-common：公共工具类
- |---- misu-net-util：网络工具类
- |---- misu-security：安全类
- |---- misu-web-starter：web服务启动类

### 环境相关
- 开发语言：Java
- 开发环境：JDK17
- 基本框架：SpringBoot3、SpringCloud、Nacos、Hibernate、QueryDSL
- 数据库：MySQL8
